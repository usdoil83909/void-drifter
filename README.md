# VOID DRIFTER

Survive the Neon Void — an original canvas-2D arcade space shooter: 20 handcrafted waves, three named bosses (Sentinel Core, Hive Queen, Void Sovereign), 5-weapon armory with tiered upgrades and a between-wave shop, procedural synth music, story intro, bestiary, pause/settings, local high scores. Runs offline in desktop Chrome from static files with no build step: serve `game/` with any static server (or `node serve.ts`) and open http://localhost:8080.

Controls: W/↑ thrust · A/D or ←/→ rotate · SPACE fire · SHIFT shield · 1-5 equip weapon · B shop · P pause · M mute
